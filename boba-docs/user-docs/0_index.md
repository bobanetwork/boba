# Introduction

Boba Network is a Layer 2, optimistic, Ethereum rollup that aims to unlock the potential of rollup technology and enable interoperability between blockchains and the real world. It's the first scaling infrastructure that is deployed on multiple blockchains, making it the leading Web3 execution layer with scaling capabilities to facilitate more functionality on EVM-compatible blockchains 

Boba establishes ETH as the base gas token, you can also use BOBA tokens as an alternate fee token using [account abstraction](./boba-hub/smart-accounts/#account-abstraction) paymasters.

Learn more about Boba through the following documentation:

- [Boba Hub](./boba-hub/index) walks through the gateway to Boba and all its resources.
- [Hybrid Compute](./hybrid-compute/index) explains one of Boba's major distinguishing features for off-chain computation.
